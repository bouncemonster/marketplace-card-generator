# Конфигурация профиля магазина (profile.json)

Профиль — единственное место, где живёт «лицо» магазина. `profile.example.json` —
рабочий пример (дизайн-система pm.market). Все поля опциональны: недостающие
берутся из `DEFAULT_PROFILE` в `cardgen.py`.

| Поле | Что задаёт |
|---|---|
| `store_name`, `niche`, `marketplaces` | контекст для арт-директора (тон брифа) |
| `language` | язык и орфографические требования (для англ. карточек: `"Correct English"`) |
| `palette` | цвета: `headline` (заголовок-доминанта), `text`, `bg`, бейдж |
| `design_system` | **главное поле**: текстовое описание композиции карточки, вставляется и в промпт арт-директора косвенно, и прямо в image-промпт. Перепишите его под свой стиль (например: «тёмный фон, золотой заголовок по центру, товар снизу») |
| `text_budget` | лимиты приёмки брифа: `max_words_subtitle`, `max_words_badge_line`, `max_chars_badge_line`, `badge_count: [min, max]`. Занижайте для дешёвых моделей, поднимать не рекомендуется |
| `banned_words` | стоп-слова валидатора брифа (список, нижний регистр, поиск по подстроке) |
| `banes_in_prompt` | строка запрета в image-промпт («без цен, без …») |
| `models.design` | LLM-арт-директор (chat/completions, желательна vision — смотрит фото товара) |
| `models.image` | генератор карточек. Seedream-семейство (`*seedream*`) автоматически включает компактный промпт и мягкую QA-политику |
| `models.qa` | vision-модель приёмки (дешёвая ok: qwen omni flash) |
| `aspect`, `resolution` | кадр (`1:1`, `3:4`, …) и разрешение (`1K`/`2K`/`4K`) |
| `min_side_px` | детерминированная проверка: минимальная сторона карточки |

## Смена стиля магазина

1. Скопируйте `profile.example.json` → `profile.json`.
2. Перепишите `design_system` под свой макет (что где лежит, цвета, плашки).
3. Поменяйте `palette` и `models.image` при необходимости.
4. Прогоните 3–5 товаров пайплайном и посмотрите `out/review_sheet.html`.
   Код менять не нужно — всё стилевое в профиле.

## Формат products.csv

Колонки: `id,title,description,category,image`. `image` — путь к локальному фото
(относительный от CSV или абсолютный). Цены/артикулы в карточку не попадают:
в промпте они запрещены, а `description` обрезается до 2500 символов.

## Журналы (out/)

| Файл | Содержание |
|---|---|
| `manifest.json` | результат scan: годность фото, форма кадра |
| `briefs.jsonl` | дизайн-брифы арт-директора (последняя запись за товар выигрывает) |
| `requests.jsonl` | собранные image-запросы (полные payload с base64) |
| `results.jsonl` | журнал генераций: status, saved, model, usage.cost — по нему работает resume |
| `qa.jsonl` | вердикты QA (det_issues, verdict, final, model) |
| `review_sheet.html` | контактный лист ручной приёмки |
| `cards/` | готовые карточки `*.jpg`, `_rN.jpg` (переген), `_fxN.jpg` (edit-починка) |

Все этапы дописывают журналы и пропускают уже сделанное — можно обрывать и продолжать,
батчить `--limit`, поднимать `--max-cost-usd`.
