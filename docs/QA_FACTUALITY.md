# QA: неподтверждённые свойства блокируют карточку

Критерий `no_invented_facts=false` означает `hard` для любого движка, в том числе Seedream. Ограничения движка по расположению товара и фразам в плашках по-прежнему могут давать `soft`; они не смягчают ложные свойства или числа.

В запрос QA передаются исходное фото, название и описание товара. Дизайн-бриф задаёт оформление и текст, но сам по себе не подтверждает свойства. Подсказка исправления требует убрать неподтверждённые свойства и числа.

## Проверка без сети

```sh
python -m unittest discover -s tests -v
```

Восемь тестов покрывают исторический BROVI verdict с `no_invented_facts=false`, разные движки, ошибочный верхнеуровневый `pass`, допустимое предупреждение о стиле, размер 1024 < 1080, ошибку провайдера, фактический контекст QA и адресную подсказку исправления. Транспорт замокан; платные запросы не выполняются.

## Ранее созданные материалы

Смена политики не переписывает старые журналы `qa.jsonl` / `image_qa.jsonl`, изображения или CSV. Команды QA сохраняют прежнее поведение resume: уже записанная пара «товар + файл» пропускается. Старое поле `final=soft` не является новой приёмкой по исправленной политике.

Для BROVI `100645945662` сохранённый verdict с `no_invented_facts=false` теперь классифицируется как `hard` при офлайн-проверке. Это исправление классификатора; публичная растровая карточка остаётся без новой приёмки. Для Soap `100070300462` отсутствие исходного фото и размер 1024×1024 остаются отдельными незакрытыми дефектами. Исправление кода не подтверждает новую генерацию или импорт в магазин.
